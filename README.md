# Квест життя для iPhone

Веб-застосунок, який встановлюється на головний екран iPhone. Відкривається з іконки на весь екран, працює офлайн, усі дані зберігаються на телефоні.

## Файли

- `index.html` — сам застосунок
- `manifest.webmanifest` — назва та іконка для головного екрана
- `sw.js` — офлайн-режим
- `icons/` — іконки

## Крок 1. Викласти в інтернет (безкоштовно, GitHub Pages)

iPhone встановлює такі застосунки тільки за адресою https://, тому папку треба один раз викласти.

1. Зареєструйтесь на github.com (якщо акаунта ще немає).
2. Натисніть «+» → **New repository**, назва, наприклад, `kvest`, тип **Public** → **Create repository**.
3. На сторінці репозиторію натисніть **uploading an existing file** і перетягніть усе з папки `kvest-iphone` (`index.html`, `manifest.webmanifest`, `sw.js` і папку `icons`) → **Commit changes**.
4. **Settings** → **Pages** → Source: **Deploy from a branch**, Branch: **main**, папка **/ (root)** → **Save**.
5. За 1–2 хвилини з'явиться адреса на кшталт `https://ВАШ-ЛОГІН.github.io/kvest/`.

## Крок 2. Встановити на iPhone

1. Відкрийте цю адресу в **Safari** (саме Safari).
2. Натисніть **Поділитися** (квадрат зі стрілкою) → **На початковий екран** → **Додати**.
3. Запускайте «Квест» з іконки.

## Резервна копія

Дані живуть тільки на цьому iPhone. У вкладці **Персонаж → Резервна копія** натисніть **Зберегти копію** і збережіть файл у «Файли» / iCloud Drive. Відновлення: **Відновити з копії**. Робіть копію хоча б раз на тиждень.

## Оновлення

Після змін у файлах завантажте їх у репозиторій знову і змініть у `sw.js` рядок `VERSION = 'kvest-v1'` на `kvest-v2` (і так далі). Застосунок на телефоні підхопить нову версію при наступному запуску з інтернетом.
